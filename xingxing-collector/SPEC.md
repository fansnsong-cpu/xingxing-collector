# ✨ 星星收集家 (Star Collector) - 游戏设计规格书

## 1. 项目概述

**项目名称：** 星星收集家
**项目类型：** 休闲合成消除 + 盲盒收集 + 放置装修
**目标平台：** 微信小程序（首发），抖音/快手小游戏（后续）
**核心体验：** 碎片化时间的收集乐趣 + 可爱角色的情感陪伴

## 2. 创新玩法设计

### 2.1 核心创新点

| 创新点 | 描述 | 玩家收益 |
|--------|------|---------|
| **COMBO连击系统** | 连续消除触发连击，分数指数增长 | 成就感、爽感 |
| **技能能量条** | 每次消除积累能量，满值触发华丽技能 | 策略性、期待感 |
| **角色羁绊** | 不同角色组合产生额外加成 | 收集动力 |
| **故事驱动** | 每个角色有完整世界观和故事线 | 情感连接 |
| **收集进度可视化** | 清晰展示收集进度和稀有角色 | 收集动力 |

### 2.2 COMBO连击系统

**连击计算：**
- 基础分 = 消除数量 × 20
- 连击加成 = 1 + (连击数 × 0.5)
- 规模加成 = 消除数量 / 3（封顶3倍）
- **最终得分** = 基础分 × 连击加成 × 规模加成

**视觉反馈：**
- 2连击以上显示 "N COMBO!" 大字
- 得分数字飘字
- 屏幕轻微震动

### 2.3 技能能量系统

**能量积累：**
- 每消除1个角色 +1能量
- 能量上限 50

**技能释放（待实现）：**
- 能量满时可释放全屏技能
- 不同角色组合触发不同技能

### 2.4 模式一：星星消消乐

**游戏类型：** 三消 + 合成 + 技能

**棋盘设计：**
- 8列 × 8行 方格
- 每格放置一个星星人角色
- 3个相同角色相连可消除

**元素类型：**
- 6种基础角色（小樱、月宝、星旅、泡泡、彩彩、夕火）
- 每个角色有 1-5星 等级
- 合成相同星级角色可升星

**技能系统：**
| 角色 | 技能 | 效果 |
|------|------|------|
| 小樱 | 樱花冲击 | 消除 3×3 范围 |
| 月宝 | 月光净化 | 消除整列 |
| 星旅 | 流星雨 | 消除整行 |
| 泡泡 | 泡泡爆炸 | 消除周围 3×3 |
| 彩彩 | 彩虹桥 | 消除所有同颜色 |
| 夕火 | 落日余晖 | 全屏消除低星级 |

**关卡设计：**
- 每关有目标（收集X个角色、得分达到Y）
- 每5关解锁一个新角色
- BOSS关卡：特殊角色需要特定技能组合

### 模式二：星空扭蛋机

**扭蛋机制：**
- 消耗「星星币」进行扭蛋
- 扭蛋结果随机获得角色/角色碎片
- 每日免费扭蛋1次

**扭蛋概率：**
| 稀有度 | 概率 | 星级 |
|--------|------|------|
| N（普通） | 60% | 1-2星 |
| R（稀有） | 30% | 3星 |
| SR（超稀有） | 8% | 4星 |
| SSR（极稀有） | 2% | 5星 |

**角色养成：**
- 角色升星：5个相同角色 → 升1星
- 角色图鉴：收集完整图鉴得奖励

### 模式三：星星小屋

**小屋功能：**
- 收集的角色会出现在小屋中
- 点击角色查看详情和故事
- 收集进度可视化展示
- 小屋风格可切换

**小屋界面功能：**
- 已收集角色展示
- 收集进度条（X/6）
- 点击角色弹出详情
- 稀有角色高亮显示

## 3. 角色故事系统

### 3.1 角色世界观
星缘大陆是一片漂浮在星光之中的神秘土地。宇宙初开时,六颗神圣的星星陨落于此,化身为六个可爱的小生灵,各自守护一种星星的力量。

### 3.2 角色设定

| 角色 | 属性 | 居住地 | 稀有度 | 技能 |
|------|------|--------|--------|------|
| 小樱 | 春之温暖 | 樱花谷 | N | 樱花冲击 |
| 月宝 | 冬之静谧 | 月光森林 | R | 月光净化 |
| 星旅 | 夏之清凉 | 流星草原 | R | 流星雨 |
| 泡泡 | 秋之丰硕 | 珍珠海湾 | N | 泡泡爆炸 |
| 彩彩 | 梦想之翼 | 彩虹之巅 | SR | 彩虹桥 |
| 夕火 | 永恒之约 | 落日火山 | SSR | 落日余晖 |

### 3.3 故事线

**主线故事:六星封印**
1. 六位守护者同时感应到神秘力量的威胁
2. 他们必须找到彼此,组成六星阵
3. 最终重新封印那股力量,守护星缘大陆的和平

**角色故事**:每个角色都有完整的诞生背景、性格特点和经典语录,详见 `CHARACTERS.md`。

## 7. 数据结构

```typescript
// 玩家数据
interface PlayerData {
  coins: number;           // 星星币
  level: number;           // 当前关卡
  characters: Character[]; // 拥有角色
  house: HouseData;        // 小屋数据
  stats: GameStats;        // 游戏统计
}

// 角色数据
interface Character {
  id: string;              // 角色ID
  star: number;            // 星级 1-5
  count: number;           // 拥有数量
  unlocked: boolean;       // 是否解锁
}

// 关卡配置
interface LevelConfig {
  id: number;
  target: LevelTarget;
  moves: number;           // 限制步数
  board: BoardConfig;      // 棋盘配置
  rewards: Reward[];
}
```
