# ✨ 星星收集家 (Star Collector)

> 泡泡玛特风格的休闲合成消除游戏，结合盲盒收集和放置装修元素

## 🎮 立即体验

打开 `demo/index.html` 即可在浏览器中体验游戏！

## 📁 项目结构

```
xingxing-collector/
├── SPEC.md                    # 游戏设计规格书
├── README.md                  # 项目说明
├── demo/
│   └── index.html            # 可运行的HTML5演示版本
└── assets/
    └── scripts/
        ├── core/             # 核心系统
        │   ├── GameManager.ts # 游戏主管
        │   ├── AudioManager.ts # 音频管理
        │   ├── StorageManager.ts # 数据存储
        │   └── AdManager.ts  # 广告管理
        ├── game/             # 游戏逻辑
        │   └── Board.ts      # 消消乐棋盘
        ├── collect/          # 收集系统
        │   └── Gashapon.ts   # 扭蛋机
        ├── home/             # 小屋系统
        │   └── House.ts      # 星星小屋
        └── ui/               # UI系统
            └── MainMenuUI.ts # 主界面
```

## 🚀 快速开始

### 方式一：直接体验（推荐）

直接用浏览器打开 `demo/index.html`

### 方式二：Cocos Creator 项目开发

1. 下载安装 [Cocos Creator 3.8+](https://www.cocos.com/creator)
2. 打开 Cocos Creator
3. 选择 "打开项目" -> 选择 `xingxing-collector` 文件夹
4. 在编辑器中打开 `assets/scenes` 下的场景
5. 点击运行按钮即可预览

## 🎯 游戏功能

### 模式一：星星消消乐
- 8×8 经典三消玩法
- 6种可爱角色（小樱、月宝、星旅、泡泡、彩彩、夕火）
- 连击combo系统
- 技能特效（3×3消除、整行整列消除等）
- 关卡递进系统

### 模式二：星空扭蛋机
- 单抽/十连扭蛋
- N/R/SR/SSR稀有度
- 角色收集与养成
- 每日免费扭蛋

### 模式三：星星小屋
- 收集的角色展示
- 角色互动动画
- 小屋升级系统

## 🎨 角色设计

6个原创角色（星星人风格）：

| 角色 | 颜色 | 稀有度 | 技能 |
|------|------|--------|------|
| 🌸 小樱 | 粉色 | N | 樱花冲击(3×3) |
| 🌙 月宝 | 紫色 | R | 月光净化(整列) |
| ⭐ 星旅 | 蓝色 | R | 流星雨(整行) |
| 🫧 泡泡 | 浅蓝 | N | 泡泡爆炸(3×3) |
| 🌈 彩彩 | 橙色 | SR | 彩虹桥(同色消除) |
| 🔥 夕火 | 红橙 | SSR | 落日余晖(全屏低星) |
